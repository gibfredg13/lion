❌ "WebSocket connection failed"
→ Check browser console (F12) for errors
→ Verify /api/realtime/breaches loads in address bar
→ Check Spring logs for WebSocketConfig messages

❌ "No LLM responses"
→ For Ollama: curl http://localhost:11434/api/tags
→ For Azure: Check credentials in logs

❌ "Java not found"
$ /usr/libexec/java_home        # Find Java (Mac)
$ export JAVA_HOME=$(/usr/libexec/java_home)
$ export PATH="$JAVA_HOME/bin:$PATH"
$ java -version         # Verify

❌ "Frontend not loading"
$ jar tf build/libs/hackmerlin-*.jar | grep index.html
$ ./gradlew clean build -x test     # Rebuild
