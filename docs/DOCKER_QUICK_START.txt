Default: Uses Ollama (local LLM, automatically setup)

To use Azure OpenAI instead:
  1. Create .env file:
     MERLIN_LLM_PROVIDER=azure
     AZURE_OPENAI_ENDPOINT=https://xxx.openai.azure.com/
     AZURE_OPENAI_KEY=sk-xxx
     AZURE_OPENAI_DEPLOYMENT=gpt-4

  2. Run: docker-compose up -d

To use Google Gemini:
  1. Create .env file:
     MERLIN_LLM_PROVIDER=gemini
     GEMINI_API_KEY=AIzaSy...

  2. Run: docker-compose up -d

❌ "docker-compose: command not found"
   → Install Docker Desktop (includes docker-compose)

❌ "Cannot connect to Docker daemon"
   → Start Docker Desktop application

❌ "Port 8080 already in use"
   $ lsof -i :8080      # Find process
   $ kill -9 <PID>      # Kill it
   # Or modify docker-compose.yml to use different port

❌ "Container keeps restarting"
   $ docker-compose logs hackmerlin    # Check error message

❌ "WebSocket not connecting"
   • Check: http://localhost:8080/ (should load)
   • Open F12 console for errors
   • Will fallback to polling if WebSocket fails

❌ "Ollama taking too long to start"
   → First startup downloads models (~2-3 GB)
   → Subsequent starts are fast
   → Check progress: docker-compose logs ollama
